# 🗣️ Lore — Conhecimento Popular

**As camadas de saber.** O mesmo fato tem quatro versões, e qual delas o grupo recebe depende de para quem perguntou. Esta página é a ferramenta de entrega: o mestre nunca narra história — ele escolhe uma coluna.

| Camada | Quem | Como se acessa |
|---|---|---|
| **1 — Popular** | Camponês, taverneiro, soldado | De graça, o tempo todo, sem teste. **Sempre parcialmente errada** |
| **2 — Erudita** | Leitor, escriba, clérigo instruído | `AST` CD 14, ou uma biblioteca e uma semana |
| **3 — Cultivador** | Ancião de clã, Mestre de escola, rank 3+ | Um favor, um Débito, ou posto na organização |
| **4 — Oculta** | Cinco pessoas por assunto, às vezes uma | Só em jogo. Ver [[Lore — Segredos do Mundo]] |

> **Regra de mesa:** a camada 1 nunca é inútil e nunca é confiável. Ela dá o gancho e erra o motivo — e é o erro que faz o grupo investigar.

## O Caminho do Fogo não funciona aqui

| | |
|---|---|

| **Oculta** | É **reversível**, em tese. Um dos quatro cadernos perdidos diz como |

## Corvan Tharn

| | |
|---|---|
| **Popular** | *"O Tirano de Kell."* Comia crianças. Assusta-se menino com o nome. **No antigo território do Consistório:** silêncio, e às vezes *"meu avô comia todo dia"* |

## Onde o grupo esbarra em cada camada

| Vetor | Camada que entrega |
|---|---|
| Taverna, mercado, guarda de portão | 1 |
| Cantiga infantil, nome de cidade, costume sem motivo | **1, mas com o dado certo escondido dentro** |
| Biblioteca de mosteiro, escriba de comarca | 2 |
| A Cúria de Lindenval | 2, e **3 se o grupo tiver o que trocar** |
| Ancião de clã, Mestre-Instrutor, um rank 3 devedor | 3 |
| Um Marcado de Kell, um Preceptor sênior bêbado, um Imortal entediado | **4** |
| Ruína, herança, Gu antigo ainda vivo | **4, sem intermediário** — o objeto não mente |

**A regra que faz isso funcionar:** objetos e lugares entregam camada 4 direto, porque não têm agenda. Pessoas entregam a camada que a posição delas permite, temperada pelo que ganham contando. É por isso que uma ruína vale mais que um arquivo.
