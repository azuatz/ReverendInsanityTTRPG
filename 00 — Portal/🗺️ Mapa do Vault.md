# 🗺️ Mapa do Vault

Índice de todo arquivo do vault, uma linha cada. Escrito pra ser lido rápido — por você ou por uma IA carregando contexto.

---

## 📖 Como carregar este vault (por onde começar)

| Situação | Carregue, nesta ordem |
|---|---|
| Mestre novo, nunca leu o romance | `🌏 O Mundo em 10 Minutos` → **`🎓 Guia do Mestre Iniciante`** → `📄 Folha de Referência` |
| Mestre que vem de D&D e quer cenário medieval | `🎓 Guia do Mestre Iniciante` → `🏰 Conversão Medieval` |
| Criando/ajustando regra de sistema | `🏛️ Arquitetura do Sistema` → a nota-mãe da pasta relevante (01–06) → a nota específica |
| Criando cenário ou sessão | `🛠️ Como Criar Sua Lore` e `🎬 Como Criar Suas Sessões` (em 08) — as pastas 07–08 são exemplo, não obrigação |
| Checando se algo é canônico do romance | `10 — Referência Canônica/Wiki` — **nunca trate como regra da mesa sem confirmar** |
| Retomando ou revisando uma decisão de design | `🧭 Log de Decisões` |
| Desconfiando de um número de balanceamento | `🎯 Simulação de Combate — Resultados` |
| Sessão de agente LLM (Claude Code) | `CLAUDE.md` (raiz) → este Mapa → últimas entradas do `log.md` |

**Divisão que organiza o vault:** pastas **01–06 são o sistema** (prontas, valem pra qualquer campanha); pastas **07–08 são cenário e sessões** (exemplo e guia, o mestre inventa o dele).
